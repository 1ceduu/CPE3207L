2. *In Section VII (Methodology), Test 1.1 – Feed Dispensing Accuracy (FDA), Pass Criterion (Page 14): "Mean FDA across all 30 trials ≥ 95%."  — **Engr. Dalin Comment**: How did you settle on the 95% accuracy?*   
     
   Response: *\[Justification added with supporting literature in both the Quantitative Metrics definition and the Test 1.1 Pass Criterion\]*   
     
   	Thank you for pointing this out. I/We agree with this recommendation. Therefore, I/we have expanded the Pass Criterion for Test 1.1 to include an explicit justification for the 95% (±5%) threshold. The revised text explains that this threshold is adopted from accuracy benchmarks reported in comparable automated feeding and precision livestock systems. Furthermore, a ±5% tolerance was selected because granular feed flow through auger mechanisms can exhibit inherent discharge variability of approximately 5% due to hopper–conveyor coupling parameters \[Chen et al., 2024; Tangorra et al., 2018\], while still remaining within nutritionally acceptable dispensing limits for swine rations. The same justification was also added to the Quantitative Metrics definition of FDA in Section VII. *This change can be found in Section VII (Methodology), Quantitative Performance Metrics subsection (FDA definition) and Test 1.1 Pass Criterion, Page 14\.*
