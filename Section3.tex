\section{Goals and Objectives}

The main objective of this project is to design and develop an integrated automated swine feeding and watering system with centralized data monitoring and control.

To achieve this goal, the system must fulfill the following specific objectives:

\begin{itemize}
  \item Implement a programmable central unit to manage main storage and automate the dispensing process.
  \item Design individual feeder modules capable of monitoring feed consumption, water availability, and ammonia levels.
  \item Develop a user interface on the central unit for system monitoring, data acquisition, and historical logging.
  \item Integrate an SMS module to alert caretakers when the system detects consumption or environmental anomalies.
\end{itemize}
